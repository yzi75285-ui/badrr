## 浏览器验证

通过 Playwright CLI 使用实际 Edge 浏览器与本机服务验证：

- 从文件选择器上传图片，预览显示，修改标题后保存，按运动筛选。
- 上传 HEVC／MOV，预览视频在浏览器中实际播放，画面尺寸 360×640，播放状态正常，无媒体错误。
- 删除有确认步骤，完成后素材从列表移除。
- 损坏文件显示失败原因，可重新预处理。
- 先选择有效文件、再选择无效文件时，旧文件被清除，提交按钮禁用。
- 人为延迟旧列表响应，期间删除素材；延迟响应释放后没有恢复已删除记录。
- 1440×1000 桌面布局与 390×844 窄屏布局已检查，窄屏无水平溢出。
- 最终页面控制台无错误或警告。

浏览器截图保存在 `output/playwright/`。窄屏检查是桌面浏览器布局检查，不属于 iOS 真机验收。仅清理了本次创建的浏览器合成测试记录。

## 当前边界

- 单文件 512 MB、视频最长 20 分钟；HEIC／HEIF 保留原片，预览需导出 JPEG。
- 上传停止等待不等于撤销已经完成的服务端保存，界面会提示先查看素材库。
- 服务仅在本机运行，尚未提供远程登录和公网部署。
- 运行环境的 Node 22 内置 SQLite 会输出实验性功能提示；当前自动化持久化与恢复测试通过。
- 动作分析、运动员参考比较、训练建议、个人 Agent 和 iOS 客户端按后续阶段实施。
