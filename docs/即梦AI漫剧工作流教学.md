# 即梦 AI 漫剧工作流教学

整理日期：2026-11-23  
适用对象：想用即梦做出第一集竖屏漫剧的人，不要求会画画、会建模。  
依据：即梦短剧工作室产品手册、画布使用手册、导演台使用手册，以及公开实操文章中与官方能力一致的做法。界面名称、积分和模型档位会改，以 [即梦](https://jimeng.jianying.com/) 当时页面为准。

本文只讲原创或已获授权的故事。不要把未授权小说、漫画、真人照片或别人的成片直接拿来生成。

---

## 1. 先建立一张地图

AI 漫剧是按集连载的动态漫画短片：角色固定，镜头之间有对白和剧情，常见时长是一集 60–90 秒，画幅多为手机竖屏 9:16。它和「随便生成一段好看视频」的差别在于，同一张脸、同一套衣服、同一个房间要跨镜头、跨集数保持住。

即梦现在有一条专门的生产线，入口叫**短剧工作室**。漫剧走的就是这条线，只是项目设置里把画面风格选成漫画、平涂、赛璐璐或国风绘本，而不是写实真人。

一条片子在工作室里的顺序是：

```text
选题与剧本
  → 项目设置（画风、比例、语言）
  → 角色 / 场景 / 道具资产
  → 分镜故事板
  → 智能预演（先看整场能不能接上）
  → 关键镜头试生成
  → 批量生成视频
  → 配音、字幕、局部重拍
  → 导出，或送到剪映精修
```

画布和 3D 导演台插在资产、分镜、生成之间。故事板负责按集按镜头往下排；画布负责把角色图、场景图、提示词和视频节点连起来改。两边共用同一套资产。

官方把剧本和分镜拆给两个模型：

| 名称 | 管什么 |
| --- | --- |
| DreamScript | 短剧结构、人物动机、节奏和台词 |
| DreamShot | 按剧本和已确认资产拆镜头：景别、动作、台词、节奏 |

视频生成主力是 Seedance。产品手册里，单段脚本时长上限可选 15 秒或 30 秒；30 秒档主要配合 Seedance 2.5。会员介绍页对 Seedance 2.5 的公开说法是：单次最长约 30 秒叙事、可挂多模态参考、可对指定片段做精准编辑。具体积分以生成按钮旁的数字为准。

## 2. 漫剧和真人短剧，开工时就要分开

两条都在短剧工作室里做，设定不同，后面返工的地方也不同。

| | 漫剧 | 真人感短剧 |
| --- | --- | --- |
| 画面风格 | 平涂、描线、赛璐璐、国风绘本、赛博漫画 | 写实、电影感 |
| 角色资产 | 三视图、正脸特写、表情九宫格，白色或纯色底 | 定妆照、多角度脸 |
| 动作 | 一个镜头一个清楚动作；对话靠切镜 | 更依赖走位、运镜和口型 |
| 声音 | 角色绑固定音色；旁白可以盖过不完美的口型 | 口型、数字人近景更重要 |
| 单集体量 | 新手先做 2–3 人、60–90 秒、一个场景 | 同样建议先短，但场景切换更多 |

漫剧最容易翻车的不是「图不好看」，而是这四件事：

1. 脸和衣服每镜都在变。
2. 一个提示词里塞了走进来、坐下、回头、爆发四件事，模型会自己压缩，动作对不上台词。
3. 小说腔直接拿去画，观众看不到内心戏。
4. 关键道具（信、瓶子、伤疤、令牌）没有单独定稿，前后长得不一样，线索就断了。

所以前期多花的时间应该在剧本、资产和分镜，而不是在最后一镜上反复抽卡。

## 3. 开工前写在纸上的四行

做第一集之前，用四行字卡住范围。写不出来就先不要打开生成。

| 要定的事 | 新手可用的范围 |
| --- | --- |
| 题材和画风 | 一个你熟悉的类型 + 一种漫画风格，全片不换 |
| 人物 | 2–3 个。每人一句外形，必须能靠颜色或配饰认出来 |
| 场景 | 第一集尽量 1 个主场景。换地方就要新的场景资产 |
| 篇幅 | 故事正文约 300 字，对应大约 60–90 秒。每集结尾停在一个看得见的动作上 |

系列剧从第二集开始，继续用已经确认的角色和场景，只追加新形象（例如换装、受伤）和新场景。官方说明：在「剧本大纲」里，AI 创作的项目用分集菜单「新建一集」；自己上传的剧本用「上传文本，解析新集」。当前手册写明，大纲里还不能单独删掉某一集，删集需要改原文后重新解析，或另开项目。

## 4. 选入口

打开即梦，进入短剧工作室，按手头材料选起点。

| 你现在有什么 | 入口 | 你要补充的话 |
| --- | --- | --- |
| 只有一句想法 | 剧本创作 | 题材、主角、故事方向、集数、每集结尾停在哪 |
| 自己的短故事或已授权小说 | 改编剧本 | 国内剧本或出海剧本；明确保留的结局和不能提前剧透的信息 |
| 已经写成场次的剧本 | 上传剧本 | txt / docx / pdf，或直接粘贴。写清集数、场景、人物、动作、台词 |

剧本格式不必工整，但层次越清楚，后面的角色和场景拆得越准。官方示例的写法可以直接套：

```text
第一集
1-1
场景：便利店冰柜前 深夜
人物：小满、老周
△ 小满蹲在冰柜前，举起一瓶没有条码的玻璃汽水。
小满：这瓶谁放进来的？
△ 老周从货架尽头走来，看见瓶子，停下。
老周：十年前，我落在这的。
```

生成结果不满意时，用对话改，不要整篇推倒。官方建议的说法都很具体，例如：「把主角换成更接地气的人设」「这一集节奏太慢，帮我压缩冲突」「把台词改得更口语」。改人名时加上「先告诉我会影响哪些内容，剧情和人物关系保持不变」，避免静默漏改。

### 剧本验收：过了再去生图

对着下面六条读一遍。有一条不过，就还停在文字阶段。

- 每句台词能直接念出来，没有书面长句。
- 每场有明确地点和时间。
- 人物在做什么，能画出来。心理活动改成动作。例如不要写「她忽然舍不得」，改成「箱盖落到一半，她用手背顶住，又把东西取出来」。
- 同一件事不要换三个地点重复做。能在一张桌子上看懂，就不要拆成三个场景。
- 每集最后停在一个画面，而不是一句感想。这个画面就是下集钩子。
- 第一集开头几秒能看出：主角是谁、此刻想要什么、什么在挡着他。

官方 Agent 提示里有一条适合开篇体检，可以原样发给它：「对前 3 集做主线体检，检查主角身份、核心冲突和观众期待是否交代清楚，先给诊断和修改建议。」

## 5. 项目设置：先锁画风和画幅

剧本可读之后，确认项目设置。这些选项会传给后面的角色、场景和视频。

| 设置 | 漫剧建议 |
| --- | --- |
| 项目名称 | 带题材和主角，例如「夜班汽水_第一季」 |
| 画面风格 | 选最接近成片的推荐风格，再微调。漫剧用漫画、平涂、赛璐璐、绘本，不要留在默认写实 |
| 画面比例 | 抖音、快手、视频号、小红书用 9:16。B 站横屏用 16:9。可选还有 21:9、1:1、4:3、3:4 |
| 角色风格 | 与画面风格同一套线稿和上色逻辑 |
| 语言和地区 | 决定台词口吻和称呼。做英文版时改语言，不要另起一套脸 |

风格一旦开生，中途全局改画风等于角色资产全部重做。第一集先用一张角色图和一张场景图试风格，满意后再批量生成资产。

## 6. 资产：角色、场景、道具

工作室会先从剧本里拆出人物小传、关系、场景和提示词，等你确认，再生成资产并铺到画布上。确认这一步不要跳。提示词里的发型、衣服颜色、标志性道具错了，后面每一镜都会跟着错。

### 6.1 角色

每个主要角色至少留下三样东西，并写进同一个角色节点：

1. **主图**：正脸半身或全身，五官清楚，纯色背景，双手自然下垂，不拿戏里才会出现的关键道具。
2. **三视图**：正面、侧面、背面。画布图片节点和角色节点都有「角色三视图」。
3. **补充参考**：脸部特写、表情九宫格。同一人的不同衣服、妆造、受伤状态，建成不同形象，不要覆写主图。

角色档案里可以填名称、形象名、出现集数，以及音色。长篇性格和经历写在文本节点里，生成时连过去，不要全塞进画面提示词。

锁定角色的操作顺序：

1. 用固定外形描述生成 4 张左右。
2. 只留一张脸型、发色、衣服颜色都干净的，设成主图。
3. 用这张主图生成三视图和表情九宫格，满意的放进该角色素材集。
4. 之后所有分镜都连接这个角色资产。不要在新镜头里重新用文字「描述一个类似的人」。

外形描述保持同一套关键词。下面是教学用的写法，把括号里的内容换成你的角色：

```text
漫画风格，平涂上色，干净线稿，
（年龄与性别），（脸型），（眉眼），（发型发色），
（服装颜色和款式），（一个始终在身上的配饰），
全身，正脸，双手自然下垂，纯白背景，五官清晰
```

反面例子是每镜都换形容词：一会「鹅蛋脸、砖红外套」，下一镜写成「可爱女孩、红色衣服」。模型会当成两个人。

### 6.2 场景

一个地点一张定稿，写清时间、光源、主色和固定陈设。同一地点的门口、柜台、里间，作为同一场景的不同视角挂在一起，不要做成三个互不相干的房间。

第一集的场景图要能回答：人物从 A 走到 B 要几步，观众能否在同一空间里看懂。竖屏构图时，提前看主体会不会被裁出画面。

### 6.3 道具

线索道具单独做一张设定图，例如缺了一角的信、没有条码的瓶子、背面有划痕的表。有两种不能混用的状态时，做两张，并规定哪一镜用哪一张。把结局才出现的状态拿去给开场当参考，剧透会直接画进第一镜。

### 6.4 资产验收

- 把角色主图缩到手机屏幕大小，仍能靠发色、衣服颜色或配饰认出是谁。
- 三视图的衣服结构前后一致，没有多出一只袖子或换了发色。
- 场景主色和角色主色能分开，人站进去不会融进背景。
- 道具在小图上仍能看出那个「只有这一件才有」的标记。

资产没过，不要进入分镜生图。

## 7. 分镜故事板

DreamShot 会把剧本拆成可生成的镜头。你要逐镜检查人物、台词、动作、景别、场景和时长。可以用对话改，例如「让女主表情更克制」「增加一个回头特写」「这段台词改得更口语」「把这一场改得更紧张」。

分镜改动可以增删、合并、翻译台词。合并时采用官方助手的限制：只合并相邻、同一场景、合并后不超过 30 秒的镜头。改完先看差异，确认后再应用。需要回退时，明确说「先不要覆盖，对比当前版本和上一版」。

### 7.1 一镜只做一件事

| 镜头号 | 景别 | 时长 | 画面（一个动作） | 台词或声音 | 引用资产 |
| --- | --- | --- | --- | --- | --- |
| 01 | 中景 | 4 秒 | 小满从冰柜第二层抽出那瓶无条码汽水 | 瓶门吸合声 | 小满、便利店、无条码瓶 |
| 02 | 近景 | 3 秒 | 她对着灯转瓶身，标签位置是空的 | 小满：「没有条码。」 | 小满、瓶子 |
| 03 | 中景 | 5 秒 | 老周停在货架尽头，看见瓶子 | 老周：「十年前，我落在这的。」 | 老周、小满、便利店 |

时长按台词来：一句短对白通常 2–4 秒，一个明显动作 3–5 秒。单段上限用项目里的 15 秒或 30 秒档，不要为了省镜头把整场戏写进一条提示词。

### 7.2 分镜验收

- 盖住文字只看画面顺序，观众能懂谁把东西交给了谁。
- 切到下一镜时，手里的道具还在同一个人手里，除非这一镜写了交接。
- 角色看向的方向接得上：双人对话先定一条轴线，近景里的视线指向对方所在的一侧。
- 每集最后一镜是钩子画面，不是总结旁白。
- 竖屏里，脸和关键道具都在安全区内，不跟字幕抢位置。

## 8. 智能预演：先花大约一成成本看整场

正式出视频前，用分集编辑器底部的「智能预演」。它会把一组镜头串起来，插入分镜参考图，用来看节奏、动作和空间，而不是看最终画质。

公开教程对官方预演手册的转述是：

- 每组至少选 3 个片段。轴上的一段算一个片段，哪怕这段提示词里写了全景和特写。
- 这一组引用的素材合计不超过 9 个。其他场次的人、废弃造型先从引用里拿掉。
- 产品手册中的演示口径：大约一段 8 秒视频的成本，可以预演一场 1 分 13 秒的戏，用来说明「先低成本看全局」。

看预演时先不要看提示词。按观众接收信息的顺序问三个问题：这一镜新告诉了我什么，道具在谁手里，下一镜的动作是不是上一镜的结果。发现剧透或接不上，先改分镜文字或替换那一张预演图，再生成正片。

单张预演图错了，可以进画布，从原图拉出修改节点，写明保留什么、只改什么。满意后加回素材，拖回对应片段。原节点如果被删，从该项目的生成历史里按图片筛选找回来。

## 9. 什么时候用 3D 导演台

导演台解决的是「说不清站位」：两人隔着柜台到底谁在左，前一镜站着、后一镜却已经坐下，环绕镜头的方向不稳定。它不替代角色资产。截图和录屏只是构图和动作参考，必须和角色图、场景图、文字提示词一起连进生成节点，脸才不会变成导演台里的白模。

推荐顺序是先静后动：

1. 摆人、摆道具、摆简单几何体，确认左右和前后。
2. 从动作库给角色套动作；要走路就加位移或轨迹。
3. 放机位，定比例、FOV 和注视点。竖屏镜头在这里就选竖图。
4. 在时间轴上打关键帧，看节奏。时间轴默认按帧，范围常常从 0 到 150 帧。
5. 静态用截图，动态用录屏，发送回画布。

提示词里写清楚你要继承什么：「参考截图的站位和前后关系；脸、衣服用角色图；动作节奏和镜头方向跟参考视频。」

一个人、一个清楚动作、机位固定的镜头，不必进导演台，直接用分镜生成更快。

## 10. 生成视频

分镜和预演通过后，先生成最容易错的镜头，再批量生成。最容易错的通常是：主角第一次出场、情绪反转、手和道具接触、双人同框。

推荐生成链：

```text
角色资产 + 场景资产 +（可选）导演台截图
        ↓
   分镜静帧，检查脸、衣服、道具
        ↓
   图生视频或首尾帧视频
        ↓
   只有这一镜不满意时，局部重拍
```

静帧不对，不要指望视频阶段把脸修好。运动会把错误放大。

写视频提示词时，把「画面里已经有的东西」和「接下来要发生的运动」分开。运动只写主体动作和镜头，例如：「镜头固定。她把瓶身转向灯光，空标签转到正对镜头，然后停住。」少写「氛围变得神秘」「背景渐渐变化」这类没有主体的句子。

实操上可以先用较快、较低清晰度看动作，动作成立后再用更高规格出成片。每次生成都消耗积分，重抽也算。

Seedance 2.5 的 30 秒档适合一条相对完整的长镜头。镜头一多、动作一复杂，仍建议拆短，用剪辑把节奏控制回来。切换模型时，让助手「保留现有分镜和资产绑定，只按新模型的时长检查哪些镜头要拆开」。

### 视频验收

- 脸在运动过程中没有换成另一个人，衣服颜色没有漂。
- 手和道具的接触看得懂，没有多指、穿模到无法阅读剧情的程度。
- 动作幅度像这一镜要表达的事，不是无意义的大幅度晃动。
- 镜头运动方向和分镜一致。
- 这一镜的时长盖得住台词，或你准备在剪辑里配旁白。

只有其中几秒坏了，用「片段重拍」或视频节点里的局部重拍，保留角色、场景和前后镜头。整段节奏错了，回到分镜，不要在坏节奏上继续生成。

## 11. 声音、字幕、成片

### 11.1 给角色固定声音

在画布的角色档案或音频节点里处理对白、旁白、音效和音乐。可用的能力包括：生成或上传音频、截取、分离人声和背景声、把音频存成音色、绑定到角色。

同一角色从第一集就绑定一条音色，后面各集继续用。两个角色的声音要能闭眼分辨。台词先改口语和多音字，再生成，不要生成完再逐字改文案。

视频模型有时会直接出环境声甚至对白。先分离音轨再听：口型能用就留，不能用就去掉原对白，改用绑定音色的配音，用旁白或反应镜头避开对不上的嘴。

即梦另有「数字人」能力：一张人物图加一段音频，生成口型、表情和声音对齐的说话视频，对正面、脸部占比大的图更稳，也支持部分动漫形象。它适合对话近景，不适合替代全片的走位镜头。产品侧对快速模式的公开说明里，建议音频不要过长（文档中的建议是 15 秒内），输入尽量单人正面。

### 11.2 在多轨里合成

把本集视频节点多选，点「编辑素材」，进入多轨编辑器。也可以先加一个多轨节点，再把素材拖进去。

多轨里可以做：

- 按分镜顺序排列画面
- 视频配音
- 字幕识别，或手打字幕并统一样式
- 去掉画面里已经生成出来、位置不对的字幕
- 片段重新生成和局部重拍

成片检查顺序：

1. 静音看一遍。不听台词也能看懂道具交给了谁、主角为什么改变行动。
2. 打开声音。台词落在对应动作之前或同时，不要说完才补画面。
3. 用手机竖屏比例看。字幕避开脸和线索道具。
4. 片尾停在钩子动作完成之后，再切黑。

导出成片，或「去剪映编辑」继续加音效、配乐和转场。配乐用剪映曲库或确认可商用的音乐。剪映里真正费时间的通常是音画对齐和补环境声，不是再切一刀。

## 12. 画布怎么连，才不会把资产用丢

短剧画布是工作室里的可视化工作台，由资产库、节点、连线组成。可以从 Agent 的「资产」阶段切进去，也可以在工作室首页直接新建空白画布。

日常只用四类节点：

| 节点 | 漫剧里放什么 |
| --- | --- |
| 文本 | 人物小传、本镜提示词、对白 |
| 图片 | 角色、场景、道具、分镜静帧。可文生图、图生图、局部重绘 |
| 音频 | 对白、旁白、音效。记得绑定角色 |
| 视频 | 图生视频、首尾帧、参考视频复刻；可抽帧、延长、重拍、去字幕 |

一条镜头的标准连线：

```text
[角色：小满] ──┐
[场景：便利店夜班] ──┼──► [图片：第02镜静帧] ──► [视频：第02镜]
[道具：无条码瓶] ──┤
[文本：镜头提示词] ──┘
```

图片节点里和漫剧关系最大的工具是：角色三视图、角色特写、表情九宫格、表情调节、局部重绘、扩图、25 宫格连贯分镜、宫格切分，以及「画面推演 3 秒后 / 5 秒前」。宫格用来看连续动作，确认后再切成单张使用。

全局设置里可以定默认风格和默认比例。做漫剧时把默认比例设成 9:16，避免角色三视图用横图、正片用竖图，裁切后手和道具被切掉。

画布人一多就乱。用颜色标签标「已定稿 / 待改 / 废弃」，用搜索按节点名定位。废弃图不要继续往下连。误删后去生成历史按类型筛选，加回画布。

工具箱可以把一组常用连线存下来，例如「角色主图 → 三视图 → 表情九宫格」。应用工具箱只会搭好结构，还要自己检查输入再点生成。

## 13. 跟着做一集：60 秒练习

下面这场戏是为本教程写的，用来走通流程。不要改成你没有版权的小说情节。

### 13.1 四行设定

- 题材：都市漫画，平涂，夜戏，暖色冰柜灯。
- 人物：小满，便利店夜班店员，黑短发，杏色工装围裙。老周，常客，灰外套，左手腕一根旧红绳。
- 场景：只在便利店冰柜到收银台这一段。
- 篇幅：第一集《没有条码》，结尾停在瓶盖内侧的刻字。

### 13.2 剧本

```text
第一集 没有条码
1-1
场景：便利店冰柜前 深夜
人物：小满、老周
△ 小满蹲下，从冰柜第二层抽出一瓶玻璃汽水。瓶身没有条码。
小满：这瓶谁放进来的？
△ 老周从货架尽头走来，看见瓶子，脚步停下。
老周：十年前，我落在这的。
△ 小满把瓶子转过来，空标签对着灯。
小满：可它是冰的。
△ 老周没有接话，看向瓶盖。
△ 切瓶盖内侧特写。小满拧开一半，金属内侧刻着两个字：小满。她的手停住。
（第一集结束）
```

发给改编或改稿助手的补充要求可以是：

```text
改成一集竖屏漫画短剧，只保留小满和老周，场景只有便利店。
先给人物小传和分集大纲。第一集必须停在瓶盖内侧露出「小满」两个字，
不要提前用旁白解释瓶子为什么是冰的。大纲等我确认后再写正文。
```

### 13.3 分镜

| 镜号 | 景别与动作 | 声音 | 时长 |
| --- | --- | --- | --- |
| 1 | 冰柜前中景。小满蹲着，抽出无条码玻璃瓶 | 瓶门吸合 | 4 秒 |
| 2 | 瓶身近景。她转到空标签，标签处是空白 | 小满：「没有条码。」 | 3 秒 |
| 3 | 货架方向中景。老周停下，看见瓶子 | 老周：「十年前，我落在这的。」 | 5 秒 |
| 4 | 双人中景。小满把空白标签转向他 | 小满：「可它是冰的。」 | 4 秒 |
| 5 | 瓶盖特写。她拧开一半，内侧刻着「小满」，手停住 | 只留瓶盖摩擦声，切黑 | 4 秒 |

先生成第 5 镜。这一镜要同时看清：还是这一只瓶子、刻的是角色名、手停在半拧。第 5 镜成立后，再预演 1–5，确认瓶子没有在第 3 镜换到老周手里。然后生成其余镜头，进多轨，静音检查一遍，再配上已经绑定的两个音色。

## 14. 提示词模板

模板只约束格式。人名、服装、场景每次都用你项目里已经定稿的词，不要临时换近义词。

### 14.1 让剧本助手先出大纲

```text
把下面的故事改成（集数）集竖屏漫画短剧。
画风：（平涂 / 赛璐璐 / 国风绘本）。
出场人物只有：（名单和每人一个可视特征）。
场景只有：（地点）。
每集写清：人物此刻要做什么、谁改变了行动、最后停在哪一个看得见的画面。
第 1 集必须停在：（钩子画面）。不要提前揭示：（秘密）。
先给人物小传和分集大纲，等我确认后再写第 1 集正文。
台词口语化，每句不超过 15 个字。
```

### 14.2 角色主图

```text
（项目画风），角色设定，纯白背景，全身，正脸，双手自然下垂，
（年龄性别），（脸型眉眼），（发型发色），（服装颜色款式），（固定配饰），
五官清晰，线条干净，不要文字，不要额外人物
```

### 14.3 单镜头视频

```text
画面继承角色图和场景图。
景别：（中景 / 近景 / 特写）。机位：（固定 / 缓慢推近 / 跟随）。
人物位置：（谁在画面左侧，看向哪一侧）。
这 4 秒只做一件事：（一个动作，写到停住为止）。
道具状态：（瓶子仍无条码，握在小满右手）。
不要切换场景，不要新增人物，不要出现字幕。
```

### 14.4 只改一张错图

```text
沿用原图的机位、人物左右和光线。
只修改：（把空白瓶身改成没有条码的玻璃汽水，瓶身仍对着灯）。
保持：（小满的黑短发、杏色围裙、左手没有入画）。
```

## 15. 出问题先回到哪一层

| 你看到的现象 | 回到哪一层改 |
| --- | --- |
| 故事没钩子、台词像旁白 | 剧本。不要继续生视频 |
| 同一个人换了脸或衣服 | 角色主图和引用。确认每个镜头都连着同一个角色资产 |
| 房间每镜都是新房间 | 场景资产。同一地点用同一张定稿和固定主色 |
| 道具状态前后矛盾 | 道具设定图。分状态做两张，检查每镜引用了哪一张 |
| 动作接不上、站位左右颠倒 | 分镜或导演台。先改文字和参考，再重生成 |
| 只有一秒手或嘴坏了 | 该片段局部重拍 |
| 口型不行但表演可用 | 分离原声，用角色绑定音色重配，字幕跟新音频 |
| 画质糊、比例错 | 检查全局比例和清晰度档位。先构图对，再提高清晰度 |
| 改了模型后镜头超时 | 保留资产绑定，按新的时长上限拆镜 |
| 审核不通过 | 按页面提示删掉或替换触发的素材，再提交 |

官方对「同一角色看起来不完全一样」的回答就是：先确认角色资产，后续分镜持续使用这一份。对「视频不满意」的回答是：先判断问题在剧本、分镜、角色、场景还是生成本身；单镜问题优先局部重拍。

## 16. 发布前的合规检查

- 故事、角色和参考图来自你的原创，或你有改编授权。换人名不等于获得了小说、漫画、影视的改编权。
- 不用真人照片、明星脸、未授权的他人肖像做参考。
- 不克隆特定真人的声音，除非你有明确授权。优先用工具音色或你自己的声音。
- 配乐和音效确认可商用。
- 画面里如果出现商标、招牌、歌词字幕，发布前处理掉。
- 做出海版本时，用工作室的语言和地区设置改台词与称呼，并重新看审核结果。

## 17. 第一集做完，怎样续

1. 角色主图、三视图、音色、场景定稿留在项目资产里，不另起一套描述。
2. 在剧本大纲追加下一集。新的一集只增加必要的新形象或新场景。
3. 下一集仍然先写「停在哪个画面」，再拆分镜。
4. 沿用同一画风、同一比例、同一片段时长上限。
5. 发布后只复盘三件事：前三秒有没有人看懂冲突，结尾钩子有没有人想看下一集，哪一个镜头因为脸或道具被你反复重抽。下一集优先改这三处的工作方式。
