# 生野 · Khepri

先读本目录 `README.md`，再读 `../docs/自用运动分析技术探索.md`。

这是独立的自用运动项目。当前只做第 1 段：电脑浏览器上传、保存、预处理和回看。分析、对比、复测、个人 Agent 和 iPhone 客户端都还没做，界面不能把它们显示成完成。

改代码时以 `server/`、`web/` 和 `contracts/` 为准。`src/` 是未接入 `npm run dev` 的 Fastify 与 SQLite 草稿，不要把它和现行服务混着改。契约已有字段的含义不再改变。

文化约束：未知保持未知；原片与预览分开；不发明姿态测量、分数或训练建议；时间轴不可靠就不提供真实时间指标。视觉用奶油底、陶土色、圆头笔画，图标不放文字。

改动留在本目录。需要更正产品范围时，可以改 `../docs/自用运动分析技术探索.md`。不要改 `../弥知 · Mimir`。

完成后运行 `npm run check` 和 `npm run test`。改了页面就在浏览器里走通上传、回看、刷新和失败重试。样本测试与本人实拍验收分开记录。
